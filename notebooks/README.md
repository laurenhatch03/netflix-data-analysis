# Python Scripts

This folder contains the Python scripts used to clean and prepare the Netflix datasets for analysis.

## Files

* **`Engagement_data_cleaning.ipynb`** — Cleans and transforms the Hours Viewed and Views datasets, then combines them into the final Engagement dataset.
* **`Top10_data_cleaning.ipynb`** — Cleans and prepares the weekly Netflix Top 10 dataset for analysis.

The original datasets and final analysis-ready datasets can be found in the [`data`](../data) folder.

See the [main README](../README.md) for additional information about the data sources, cleaning process, and project methodology.
