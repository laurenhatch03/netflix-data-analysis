# SQL Analysis

This folder contains the SQL scripts used to build, validate, and analyze the Netflix datasets.

### Files

* **`database_setup.sql`** — Creates the Netflix database, builds the `financials`, `engagement`, and `top10` tables, and loads the cleaned datasets into MySQL.

* **`financial_analysis.sql`** — Analyzes Netflix's financial performance, including revenue growth, profit margins, cash flow vs. CapEx, and overall financial performance by year.

* **`engagement_analysis.sql`** — Analyzes viewer engagement by year, reporting period, title, and content type using hours viewed and views.

* **`top10_analysis.sql`** — Analyzes Global Top 10 performance, including longest Top 10 presence, total hours viewed, total views, average ranking, and #1 rankings.

* **`data_validation.sql`** — Checks data quality by validating row counts, date ranges, duplicate financial years, missing titles, engagement metrics, and Top 10 categories.

Together, these scripts support the SQL portion of the Netflix data analysis project and help validate findings from the Python and Power BI analysis.
