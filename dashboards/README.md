# Dashboards

This folder contains the Power BI dashboards created for the Netflix Data Analysis project.

### Dashboard Pages

* **Financial Performance** — Analyzes Netflix's revenue, profitability, cash flow, assets, liabilities, and content assets over time.
* **Engagement** — Analyzes viewing hours, views, and title-level engagement across Movies and TV Shows.
* **Top 10** — Analyzes Global Top 10 rankings, weekly viewing activity, content categories, and sustained Top 10 performance.

The dashboards provide an interactive visual summary of the findings from the Excel, Python, and SQL analysis.
